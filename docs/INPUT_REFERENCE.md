# 조작 레퍼런스 조사: Snake.io

- 확인일: 2026-10-17
- 확인 방법: 공식 사이트 튜토리얼과 제작사 공식 블로그
- 범위: 공개 안내 문서. 실제 플레이 입력이나 내부 코드를 검사한 결과가 아님

## 공식 자료로 확인한 내용

| 항목 | 확인 결과 | 출처 |
| --- | --- | --- |
| PC 방향 제어 | 마우스, WASD, 방향키 | 공식 게임 페이지 |
| PC 마우스 | 추종형(follow-type) 이동 | 공식 플랫폼 가이드 |
| PC 부스트 | 좌클릭 또는 스페이스 유지 | 공식 게임 페이지·튜토리얼 |
| 모바일 | Joystick, Arrow, Follow 선택 | 공식 튜토리얼 |

PC는 좌클릭이 부스트이므로 마우스 이동을 '좌클릭할 때마다 고정 목적지를 찍는 방식'으로 해석하면 안 됩니다. 문서상 마우스 추종으로 방향을 제어하는 구조입니다.

## 이 자료만으로는 확인하지 못한 내용

- 모바일 Follow에서 손을 뗐을 때의 이동 지속 여부
- 캐릭터 중심 근처에 포인터를 둘 때 정지·방향 유지·회전 중 어느 처리를 하는지
- 카메라 이동 시 포인터의 화면 좌표와 월드 좌표 처리
- 누르고 드래그하거나 화면 밖으로 나간 입력의 처리

따라서 이 세부 조건에 대해 'Snake.io와 동일하게 구현'이라는 요구만으로 판정 로직을 확정하지 않습니다.

## MutatIO 적용

- 확정: WASD, 방향키, 좌하단 고정 가상패드, 터치/마우스 추종의 네 선택지.
- 확정: PC 마우스는 클릭 없이 커서 방향을 추종하며 클릭 해제 후에도 추종합니다. 고정 목적지 클릭 이동은 사용하지 않습니다.
- 확정: PC 마우스 모드의 월드 좌클릭으로 대시하며 기존 스페이스도 유지합니다. 모바일은 대시 버튼입니다.
- 확정: UI 입력은 월드 이동 방향을 바꾸지 않습니다. UI 클릭은 월드 대시와 중복 처리하지 않고 이동 터치와 대시 터치를 구분합니다.
- 미결정: 좌클릭 유지 시 반복 대시, 중심 데드존과 카메라 좌표 처리, UI 위에서의 기존 이동 처리.
- 모바일 테스트 제안(미승인): 누르는 동안 화면상 터치 방향으로 이동하고 해제/중심에서 입력을 0으로 한 뒤 관성 감속.
- 위 모바일 제안은 Snake.io 실기 확인 결과가 아닙니다.
- Snake.io의 지속 부스트·질량 소모를 MutatIO의 대시 규칙으로 가져오지 않습니다. MutatIO는 순간 가속과 쿨타임을 이미 정했습니다.

## 확인 체크리스트

플랫폼과 버전을 명시하고 PC Mouse 및 모바일 Follow를 각각 확인합니다.

1. 클릭하지 않고 마우스만 움직이기
2. 누른 뒤 드래그하고 해제하기
3. 포인터를 캐릭터 중심에 두기
4. 이동 중 화면상 포인터 위치를 고정하기
5. UI 버튼·부스트 버튼에 두 번째 입력 넣기

## PlayerPrefs 기술 참고

Unity 공식 문서는 세션 간 설정 저장을 지원하며 Web에서는 IndexedDB에 저장한다고 안내합니다. 캐릭터 식별자·닉네임·조작 모드 같은 이전 선택 복원에 사용합니다. 사이트 데이터가 삭제되면 기본값으로 복구하고, 이를 계정 동기화나 진행상황 이어하기로 확대하지 않습니다.

- https://docs.unity3d.com/6000.3/Documentation/ScriptReference/PlayerPrefs.html
