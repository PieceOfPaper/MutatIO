# MutatIO 게임 기획서

- 문서 상태: 플레이 흐름과 기본 규칙 구체화
- 마지막 갱신: 2026-10-17
- 기준 저장소 커밋: fb8a4b1359664fcadcac83ab9089d87c0e549895
- 목적: 코딩 에이전트와 사람이 공유하는 게임 구현 기준

이 문서의 규칙은 구현 목표이며 구현 완료를 뜻하지 않습니다. **확정**, **제안**, **미결정**을 구분합니다. 구체적인 수치는 [미결정 기획 항목](OPEN_DESIGN_QUESTIONS.md)에서 관리하고, 기존 규칙의 변경 이유는 [결정 기록](DECISIONS.md)에 남깁니다.

## 1. 게임 개요

모든 플레이어가 작은 초식 생명체로 시작해 먹으며 점수와 몸집을 키우는 생태계형 실시간 IO 게임입니다. 초식 생명체가 죽으면 그동안 먹은 양에 비례한 육식 먹이가 생성됩니다. 이를 일정량 먹은 초식 생명체는 육식 생명체로 변이하여 자신보다 작은 다른 생명체를 접촉으로 처치할 수 있습니다.

먹지 않으면 굶어 죽고, 성장할수록 주변에 위협이 되거나 가치 있는 먹잇감이 됩니다. 월드는 고정된 라운드 시작 없이 운영되며 누구나 중간에 들어오고 나갈 수 있습니다.

## 2. 용어와 외형

| 용어 | 의미 |
| --- | --- |
| 초식 생명체 | 모든 플레이어가 처음 시작하는 상태. 기존 문서의 기본 생명체 |
| 육식 생명체 | 육식 먹이를 일정량 섭취해 변이한 상태. 기존 문서의 포식자 |
| 초식 먹이 | 필드에 주기적으로 생성되는 초록색 자원. 기존 문서의 기본 먹이 |
| 육식 먹이 | 초식 생명체 사망 시 생성되는 붉은색 자원. 기존 문서의 생체 물질 |
| 포만 게이지 | 남은 생존 여유를 표시하는 게이지. 시간이 지나면 감소하고 먹으면 회복 |
| 섭취량 | 이번 생에 먹은 먹이의 누적량. 점수·성장·초식 사망 드롭 산정의 근간 |
| 몸집 | 섭취량에 따라 커지는 캐릭터 크기. 접촉 승패와 카메라 범위에 사용 |

초식·육식은 게임 역할을 설명하는 작업용 명칭입니다. 최종 세계관은 인간이 아닌 외계 생명체·미생물 등의 방향을 선호하며 아직 확정하지 않았습니다.

### 캐릭터 선택과 역할 표시 — 확정

- 입장 전에 캐릭터 외형을 선택합니다. 초식·육식 역할을 선택하는 과정은 아닙니다.
- 초식과 육식은 색으로 구분합니다. 정확한 캐릭터 색상은 미결정입니다.
- 캐릭터 바리에이션은 색보다 형태 차이를 중심으로 구성합니다.
- 월드의 캐릭터는 원형을 기본으로 표시합니다.
- 원형 표현 안에서 실루엣·표면·눈·장식 등의 차이를 어떻게 줄지는 미결정입니다.
- 캐릭터 선택에 따른 능력치 차이는 확정된 기능이 아닙니다.

## 3. 전체 플레이 흐름

```text
첫 화면: 캐릭터 선택 + 닉네임 입력
                ↓
입장 전 이동 조작 방식 선택
                ↓
작은 초식 생명체로 월드 입장
                ↓
이동 → 먹이 자동 흡수 → 점수·몸집 증가
                ↓
육식 먹이 누적 섭취 시 육식 생명체로 변이
                ↓
먹이 경쟁·대시·접촉 판정·굶주림
                ↓
사망 → 이번 플레이 결과 표시
                ↓
확인 버튼 → 첫 화면으로 복귀
```

조작 방식을 입장 전에 선택할 수 있어야 한다는 점은 확정입니다. 선택 화면의 정확한 배치는 아래 제안에 해당합니다. 사망 직후 자동으로 월드에 부활하지 않으며, 첫 화면에서 다시 입장할 때 작은 초식 생명체로 시작합니다.

## 4. 입장 화면과 조작 선택

### 입장 준비 — 확정

- 캐릭터 외형을 선택합니다.
- 닉네임을 입력합니다.
- 이동 조작 방식을 선택한 뒤 월드에 진입합니다.
- 모든 플레이어는 같은 작은 초식 상태로 시작합니다.
- 계정 생성이나 로그인은 현재 확정된 입장 조건이 아닙니다.

### 화면 배치 — 제안

캐릭터 선택·닉네임 입력·조작 선택·입장 버튼을 첫 화면 하나에 배치하는 구성을 권장합니다. 조작 선택을 별도 필수 화면으로 만들지 않으면 설정을 한눈에 확인하고 곧바로 입장할 수 있습니다.

기기별 기본값과 이전 선택 기억, 설정에서의 조작 변경은 후속 결정 대상입니다. 이 제안을 승인된 UI 구조로 간주하지 않습니다.

### 이동 조작 두 종류 — 확정

| 방식 | 데스크톱 입력 | 터치 입력 |
| --- | --- | --- |
| 방향 입력형 | 키보드로 이동 | 화면 내 가상 조이스틱으로 이동 |
| 포인터 입력형 | 마우스 포인터를 누른 위치로 이동 | 터치한 위치로 이동 |

- 조작 감각의 레퍼런스는 Snake.io입니다.
- 레퍼런스의 세부 동작을 검증하지 않은 상태에서 그대로 구현했다고 간주하지 않습니다.
- 키 배치, 누르는 동안만 이동하는지, 손을 뗀 뒤에도 이동하는지, 목표점에 도착하면 멈추는지 등은 미결정입니다.
- 두 방식은 같은 캐릭터 이동 규칙과 게임 판정을 사용합니다.

## 5. 월드 화면과 HUD — 확정

| 위치 | 표시 |
| --- | --- |
| 화면 좌측 상단 | 점수 랭킹 |
| 화면 우측 상단 | 각종 설정 버튼 |
| 각 캐릭터 머리 위 | 해당 캐릭터의 닉네임과 남은 포만 게이지 |
| 모바일 조작 영역 | 선택한 방식에 필요한 가상 조이스틱과 대시 버튼 |

포만 게이지는 가득 찰수록 생존 여유가 많고 시간이 지나면 줄어드는 방향으로 표현합니다. 본인뿐 아니라 다른 캐릭터의 닉네임과 게이지도 표시합니다.

랭킹의 표시 인원, 동점 처리, 설정 항목, UI 겹침 처리, 대시 버튼 위치는 미결정입니다.

## 6. 먹이·점수·성장

### 먹이 생성 — 확정

| 구분 | 표시 색상 | 생성 조건 |
| --- | --- | --- |
| 초식 먹이 | 초록색 | 일정 공간 간격과 시간 주기로 리젠 |
| 육식 먹이 | 붉은색 | 초식 생명체가 죽었을 때만 생성 |

- 초식 먹이의 정확한 배치 방식, 랜덤성, 생성 주기와 최대 개수는 미결정입니다.
- 육식 먹이의 생성량은 죽은 초식 생명체가 이번 생에 먹은 양에 비례합니다.
- 이번 안에서는 육식 생명체가 죽어도 육식 먹이를 남기지 않습니다. 이는 기존의 모든 개체 사망 시 드롭 규칙을 대체합니다.
- 최초 포식자를 만들기 위한 초기 사체나 필수 NPC를 별도로 배치하지 않습니다. 포식자가 없는 월드도 정상 상태입니다.

### 먹이 흡수 — 확정

- 이동 중 먹이에 일정 거리 안으로 접근하면 먹이가 자석처럼 캐릭터 쪽으로 당겨집니다.
- 별도 먹기 버튼을 누르지 않고 자동으로 섭취합니다.
- 실제 섭취가 완료되면 점수가 오르고 몸집이 커집니다.
- 먹이는 허기를 회복하여 생존을 유지하는 자원이기도 합니다.

흡수 반경, 당겨지는 속도, 동시에 여러 개체가 접근했을 때의 소유권, 섭취 완료 시점은 미결정입니다. 시각적인 흡수 연출과 보상 판정은 구분하고 하나의 먹이 보상이 중복 지급되지 않아야 합니다.

### 점수와 크기 — 확정 및 미결정

먹은 양이 점수이며 먹을수록 몸집이 커집니다. 점수에서 외형 크기와 충돌 크기로 변환하는 곡선, 먹이별 단위 가치, 상한은 미결정입니다.

현재 질량과 누적 점수를 별도 값으로 관리할지, 굶을 때 점수나 몸집이 감소할지는 결정하지 않았습니다. 킬 자체에 별도 점수를 주는 규칙도 현재 확정안에 포함하지 않습니다.

## 7. 허기와 변이

### 허기 — 기존 방향 유지

- 시간이 지나면 남은 포만 게이지가 감소합니다.
- 먹이를 먹으면 회복합니다.
- 먹지 못하면 결국 사망합니다.
- 감소율, 몸집과의 관계, 게이지가 0이 된 뒤 사망까지의 절차는 미결정입니다.

### 육식화 — 기존 방향 유지

- 초식 생명체도 육식 먹이를 먹을 수 있습니다.
- 초식 상태에서는 육식 먹이의 허기 회복 효율이 낮으며, 최초 아이디어는 육식 상태에서 먹을 때의 절반 효율입니다.
- 육식 먹이를 일정량 먹으면 육식 생명체로 변이합니다.
- 변이하면 색을 통해 역할 변경을 구분할 수 있어야 합니다.

변이 임계치, 누적 수치 감소 여부, 변이 시 몸집 변화, 육식 상태의 초식 먹이 섭취 가능 여부는 미결정입니다.

## 8. 접촉 전투 — 확정

별도 공격 버튼 대신 캐릭터 간 접촉과 상대적 몸집으로 사망을 판정합니다.

| 접촉 조합 | 결과 |
| --- | --- |
| 초식 ↔ 초식 | 접촉으로 사망하지 않음 |
| 큰 육식 ↔ 작은 초식 | 초식 사망 |
| 작은 육식 ↔ 큰 초식 | 육식이 초식을 죽이지 못함. 육식 사망 여부는 미결정 |
| 큰 육식 ↔ 작은 육식 | 작은 육식 사망 |
| 동일 몸집이 포함된 육식 접촉 | 결과 미결정 |

- 초식의 사망으로 생성된 먹이는 별도로 흡수하여 점수를 얻습니다.
- 접촉 처치가 곧 즉시 섭취를 뜻하지는 않습니다.
- 초식끼리의 밀침·통과 여부, 원형 접촉 범위, 동시 접촉 순서, 판정에 사용할 정확한 크기값은 미결정입니다.
- 크기 우위에 필요한 최소 차이 또는 비율 역시 미결정입니다.

## 9. 카메라 — 확정

- 내 캐릭터가 커질수록 카메라가 보여주는 월드 영역도 넓어집니다.
- 성장이 캐릭터를 화면 밖으로 밀어내지 않도록 설계합니다.
- UI는 월드 카메라의 표시 범위와 별개로 화면 기준 위치를 유지합니다.

정확한 시점, 줌 곡선, 최대 표시 범위, 보간 속도와 화면 비율별 처리 기준은 미결정입니다.

## 10. 대시 — 확정

- 캐릭터는 순간적으로 빠르게 이동하는 대시를 사용할 수 있습니다.
- 키보드는 스페이스 키로 사용합니다.
- 모바일은 화면 내 대시 버튼으로 사용합니다.
- 대시 후에는 짧은 재사용 대기시간이 있습니다.

속도 배율, 지속시간, 쿨타임 수치, 사용 방향, 자원 소모, 대시 중 접촉 판정 변화와 PC 포인터 모드의 추가 입력은 미결정입니다.

## 11. 사망과 결과 — 확정

- 사망하면 해당 생의 플레이를 종료하고 결과 화면을 표시합니다.
- 결과 화면에는 이번 플레이에서 얼마나 모았는지, 즉 최종 획득 점수·누적 섭취 성과를 확인할 수 있어야 합니다.
- 확인 버튼을 누르면 캐릭터 선택과 닉네임 입력이 있는 첫 화면으로 돌아갑니다.
- 다시 입장하면 작은 초식 생명체로 시작합니다.

생존 시간·최고 순위·처치 수 등 추가 결과 항목과 기록의 영구 저장 여부는 미결정입니다. '전적'이라는 표현만으로 계정별 영구 기록 시스템을 구현하지 않습니다.

## 12. 생태계 순환과 검증 주의점

```text
초식 입장 → 초식 먹이 섭취·성장 → 자원 경쟁
  → 초식 사망 → 붉은 먹이 발생 → 초식의 고기 섭취·변이
  → 큰 육식의 접촉 처치 → 초식 감소
  → 육식의 먹이 경쟁·접촉 사망·굶주림
  → 결과 확인 후 첫 화면 → 다시 초식으로 입장
```

이는 의도하는 순환이며 자연적으로 균형을 보장하는 것은 아닙니다. 특히 육식은 고기를 남기지 않으므로 육식 간 전투는 먹이 확보보다 경쟁자 제거의 의미를 가집니다. 초식 감소 시 육식 먹이의 공급이 끊기는 속도를 테스트해야 합니다.

## 13. 아직 확정하지 않은 확장 기능

계정, 영구 성장, 시즌, 수익화, 스킨 능력, 파티, 진화 트리, 필수 AI, 여러 맵, 관전·리플레이는 확정 범위에 포함하지 않습니다.
