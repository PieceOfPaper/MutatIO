# MutatIO 게임 기획서

- 문서 상태: 초기 확정안
- 마지막 갱신: 2026-10-17
- 목적: 구현과 후속 기획의 기준이 되는 핵심 규칙 기록

수치와 세부 전투 방식은 아직 확정되지 않았습니다. 이 문서에서 확정된 방향과 [결정 기록](DECISIONS.md)을 구현 기준으로 사용합니다.

## 1. 한 줄 설명

모든 플레이어가 작은 생명체로 시작해 먹으며 성장하고, 죽은 개체의 생체 물질을 섭취하면 포식자로 변이하는 생태계형 실시간 IO 게임입니다.

## 2. 핵심 경험

- 먹는 행위가 생존, 점수, 성장에 동시에 연결됩니다.
- 평화롭게 자원을 수집하던 개체가 생존을 위해 고기를 먹고 포식자로 변할 수 있습니다.
- 큰 개체의 죽음은 많은 먹이를 남겨 주변 생태계에 새로운 경쟁을 만듭니다.
- 플레이어 수와 자원량에 따라 평화로운 성장과 추격전의 비중이 자연스럽게 변합니다.
- 고정된 술래와 도망자가 아니라 플레이 도중 역할이 발생하고 순환합니다.

## 3. 세계와 표현 방향

초기 논의는 초식동물과 육식동물이었지만 최종 표현은 사람이나 현실 동물에 한정하지 않습니다.

현재 선호 방향은 다음과 같습니다.

- 외계 생명체, 미생물, 세포, 포자 또는 바이러스에서 착안한 존재
- 기본 개체는 비교적 순하고 단순한 형태
- 생체 물질을 먹을수록 외형이 변하고 공격적인 포식 형태가 됨
- 먹은 양과 몸집의 관계를 시각적으로 쉽게 이해할 수 있어야 함

정확한 아트 콘셉트와 명칭은 아직 미결정입니다. 기획 용어로는 아래 표현을 사용합니다.

| 기획 용어 | 의미 |
| --- | --- |
| 기본 생명체 | 모든 플레이어가 처음 시작하는 비공격적 상태 |
| 기본 먹이 | 필드에 시간에 따라 생성되는 자원. 기존 논의의 풀 |
| 생체 물질 | 생명체가 죽었을 때 남는 먹이. 기존 논의의 고기 |
| 포식자 | 생체 물질을 일정량 섭취해 변이한 공격 가능 상태 |
| 허기 | 먹지 않으면 감소하며 생존을 압박하는 자원 |
| 질량 | 먹은 양에 따라 증가하고 외형 크기에 반영되는 성장값 |

## 4. 핵심 규칙

### 4.1 접속과 시작

- 플레이어는 진행 중인 공간에 자유롭게 입장하고 퇴장할 수 있습니다.
- 고정된 라운드 시작을 기다리지 않습니다.
- 모든 플레이어는 작은 기본 생명체로 시작합니다.
- 처음부터 포식자를 선택해 입장하지 않습니다.
- 사망 후에도 작은 기본 생명체로 다시 시작합니다.

### 4.2 기본 먹이

- 기본 먹이는 필드에 시간에 따라 생성됩니다.
- 기본 생명체는 기본 먹이를 먹어 허기를 회복합니다.
- 먹은 양은 점수에 반영됩니다.
- 먹은 양에 따라 질량과 외형 크기가 증가합니다.
- 기본 생명체 수가 늘면 같은 먹이를 두고 경쟁하게 됩니다.

구체적인 생성 위치, 생성률, 희귀 먹이, 지역별 차이는 미결정입니다.

### 4.3 허기와 죽음

- 모든 플레이어는 시간이 지나면 허기가 감소합니다.
- 먹이를 섭취하지 못하면 결국 죽습니다.
- 기본 생명체가 과밀해지면 기본 먹이가 부족해지고 자연스럽게 사망 개체가 발생할 수 있습니다.
- 게임 시작 시 포식자가 없어도 정상입니다. 최초의 생체 물질과 포식자는 플레이 과정에서 발생합니다.

허기 감소 공식과 허기 0 이후 즉사·체력 감소·질량 소모 여부는 미결정입니다.

### 4.4 사체와 생체 물질

- 생명체가 죽으면 필드에 생체 물질을 남깁니다.
- 생체 물질의 양은 사망 당시 개체의 몸집에 비례합니다.
- 큰 개체의 죽음은 여러 플레이어가 경쟁할 수 있는 중요한 사건이 됩니다.
- 사망한 플레이어는 사체와 별개로 기본 생명체로 재시작합니다.

질량 중 몇 퍼센트가 생체 물질로 환원되는지, 사체 유지 시간과 분배 방식은 미결정입니다.

### 4.5 육식화와 변이

- 기본 생명체도 생체 물질을 먹을 수 있습니다.
- 기본 생명체에게 생체 물질은 기본 먹이보다 허기 회복 효율이 낮습니다.
- 생체 물질을 먹을수록 육식화 또는 변이 수치가 누적됩니다.
- 일정량을 먹으면 포식자로 변합니다.
- 포식자는 다른 기본 생명체와 포식자를 공격할 수 있습니다.
- 포식자는 사냥 후 생체 물질을 먹어 허기와 점수, 질량을 얻습니다.

변이 임계치, 변이의 가역성, 변이 연출, 변이 시 질량 보존율은 미결정입니다.

### 4.6 점수와 성장

- 먹은 양이 점수의 근간입니다.
- 점수 상승은 질량과 외형 크기 증가로 체감되어야 합니다.
- 기본 생명체는 기본 먹이를 통해 비교적 안정적으로 성장합니다.
- 포식자는 사냥에 성공하면 더 빠르게 성장할 가능성이 있습니다.
- 죽으면 현재 성장 상태를 잃고 작은 기본 생명체로 돌아갑니다.

점수가 현재 질량과 완전히 동일한지, 누적 점수와 현재 질량을 분리할지는 미결정입니다.

## 5. 생태계 순환

```text
작은 기본 생명체로 시작
        ↓
기본 먹이를 먹어 허기·점수·몸집 증가
        ↓
개체 수 증가와 먹이 경쟁
        ↓
먹이 부족과 굶주림
        ↓
사망한 개체가 생체 물질을 남김
        ↓
기본 생명체가 생체 물질을 섭취
        ↓
누적 섭취량에 따라 포식자로 변이
        ↓
다른 생명체를 사냥하며 성장
        ↓
기본 생명체 감소와 포식자 간 경쟁
        ↓
포식자의 먹이 부족 또는 전투 사망
        ↓
생체 물질을 남기고 기본 생명체로 재시작
        ↺
```

## 6. 플랫폼과 조작

- 주 플랫폼은 웹 브라우저입니다.
- Unity WebGL을 기준으로 개발합니다.
- 데스크톱에서는 키보드와 마우스로 조작할 수 있어야 합니다.
- 터치 환경에서는 게임 화면 안의 가상 조이스틱으로 조작할 수 있어야 합니다.
- 두 입력 방식은 동일한 게임 규칙과 이동 시스템을 사용해야 합니다.

세부 조작, 공격 입력, 자동 공격 여부, 모바일 브라우저 지원 범위는 미결정입니다.
