캐릭터 선택과 닉네임 입력, 두 이동 방식, HUD 위치, 머리 위 닉네임·포만 게이지, 자석형 먹이 흡수, 먹이 색상, 초식 사망 전용 드롭, 몸집 기반 접촉 처치, 성장 연동 카메라, 대시, 사망 결과와 첫 화면 복귀를 구체화했습니다. 규칙 선택은 아래 질문으로, 테스트로 조정할 값은 [밸런스 데이터 목록](BALANCE_PARAMETERS.md)으로 관리합니다.

## P0 — 화면과 조작

### 확정 또는 방향이 정해진 항목

- 첫 화면에 캐릭터·닉네임·조작 선택을 함께 배치합니다.
- WASD / 방향키 / 가상패드 / 터치/마우스 추종의 네 선택지를 제공합니다.
- 가상패드는 좌하단에 고정합니다.
- 별도 회전속도 제한 없이 약한 관성을 적용합니다.
- 큰 캐릭터일수록 이동속도가 완만히 감소하게 합니다.
- 대시는 현재 이동 방향, 정지 중에는 마지막 유효 이동 방향을 사용합니다.
- PC 대시는 스페이스를 사용하며 마우스 모드에서는 좌클릭으로도 사용합니다.
- PC 마우스는 클릭 없이 커서를 추종합니다. UI 버튼 입력으로 월드 이동 방향이 바뀌지 않으며 UI 클릭은 월드 대시와 중복 처리하지 않습니다.
- 이동 터치와 대시 버튼 터치를 분리합니다.
- 캐릭터·닉네임·조작 모드는 PlayerPrefs로 저장하고 복원합니다.

### 남은 규칙 질문

- [Snake.io 조사](INPUT_REFERENCE.md)로 추종형 이동은 확인했으나 손을 뗄 때/중심 접근/카메라 이동 세부 처리는 미확인입니다.
- 모바일 터치 해제와 캐릭터 중심 접근 시 정지 입력을 줄지, 마지막 방향을 유지할지?
- PC 마우스 중심 접근 시 어떻게 처리할지?
- 좌클릭을 누른 채 유지할 때 대시는 최초 한 번만 사용할지, 쿨타임마다 반복할지?
- 마우스 추종의 카메라 이동·줌 변화 시 좌표 갱신 세부 기준은 무엇인가? 고정 클릭 목적지 이동은 사용하지 않습니다.
- 대시 중 방향 전환이 가능한가? 입장 후 첫 이동 전 대시의 기본 방향은?
- 대시 비용을 쓰는가? 쓴다면 점수·허기 중 어떤 자원인가?
- 첫 실행의 기본 조작과 기기에서 사용할 수 없는 선택지를 어떻게 표시하는가?
- 플레이 도중 설정에서 조작 변경을 허용하는가?
- PC 커서가 UI 위에 있을 때 기존 이동 방향을 유지할지, 감속할지?
- 설정 창을 열면 기존 이동을 멈추는가? 온라인 월드의 진행 자체는 어떻게 다루는가?

가속·감속·크기별 속도 곡선·데드존·대시 배율·시간·비용량은 [밸런스 데이터 목록](BALANCE_PARAMETERS.md)에서 관리합니다.

## P0 — 성장과 먹이

- 먹은 양의 기준 단위를 무엇으로 정의할 것인가? 먹이별 값은 밸런스 데이터 목록에서 관리합니다.
- 누적 점수와 현재 질량을 분리할 것인가? 굶으면 점수 또는 몸집이 줄어드는가?
- 점수·질량·외형 크기·충돌 반경 사이 관계를 어떻게 정의하는가? 곡선 수치는 밸런스 데이터 목록에서 관리합니다.
- 초식 먹이는 격자·영역·랜덤 중 어떤 방식으로 배치하는가?
- 초식 먹이 최대 개수, 점유 위치 재생성, 서버 인원별 공급 조정이 필요한가?
- 자석 흡수 반경은 몸집에 비례하는가?
- 여러 개체가 같은 먹이에 접근했을 때 누가 흡수하는가?
- 흡수 도중 캐릭터가 사망·이탈하거나 변이하면 먹이는 어떻게 처리하는가?
- 드롭 총량을 조각 수와 조각당 영양량으로 어떻게 분배하는가? 환원율·범위·유지시간은 밸런스 데이터 목록에서 관리합니다.

## P0 — 허기·변이·접촉 판정

- 허기 감소율에 몸집·역할별 배율을 적용하는가?
- 포만 게이지 0에서 즉사, 체력 감소, 질량 소모 중 무엇을 적용하는가?
- 초식의 고기 회복 효율은 밸런스 데이터 FOOD-06에서 비교합니다.
- 변이 누적량은 시간에 따라 줄어드는가? 임계 수치는 밸런스 데이터 MUTATE-01에서 관리합니다.
- 육식 전환 시 몸집을 보존하는가? 전환 시점과 예고는 어떻게 표시하는가?
- 육식은 초식 먹이를 먹을 수 있는가? 먹는다면 점수와 허기는 어떻게 처리하는가?
- 같은 몸집끼리 육식이 포함된 접촉을 하면 어떻게 되는가?
- 작은 육식과 큰 초식이 닿았을 때 육식은 죽는가, 양쪽 모두 살아남는가?
- '더 크다'의 판정값과 최소 우위 차이 또는 비율은 무엇인가?
- 원형 충돌 반경과 시각적 외형의 관계는 무엇인가?
- 초식끼리 접촉 시 통과하는가, 서로 밀리는가?
- 여러 개체가 동시에 접촉하거나 같은 순간 성장·변이하면 어떤 순서로 처리하는가?
- 대시 중에도 동일한 접촉 판정을 사용하는가?
- 스폰 위치와 보호 시간을 어떻게 정하는가?

육식 사망 시 고기를 생성하지 않는 규칙은 확정했습니다. 변경하려면 별도 결정을 기록합니다.

## P0 — 카메라와 캐릭터 표현

- 정확한 시점은 탑다운 2D인가? 원형 표현만으로 시점까지 확정하지 않습니다.
- 카메라 범위와 몸집의 관계를 어떤 방식으로 정의하는가? 줌 곡선·상한·보간값은 밸런스 데이터에서 관리합니다.
- 맵 경계와 화면 비율별 최소 가시 영역은 어떻게 처리하는가?
- 원형을 유지하면서 캐릭터별 형태 차이를 어떻게 표현하는가?
- 초식·육식 캐릭터 색상은 무엇인가? 먹이의 초록·빨강과 어떻게 구분하는가?

- 대시 버튼 위치와 쿨타임 표시
- 변이 진행도 표시
- 결과의 필수 획득 점수 외 생존 시간·최고 순위·처치 수 등의 추가 통계
