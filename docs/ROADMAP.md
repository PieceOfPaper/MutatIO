# 개발 로드맵

- 문서 상태: 제안
- 마지막 갱신: 2026-10-17

이 로드맵은 기능 약속이 아니라 검증 순서입니다.

## Phase 0 — 기획 기반 정리

- [x] Unity 프로젝트와 저장소 생성
- [x] Unity CLI 및 Pipeline 패키지 포함
- [x] 핵심 생태계 규칙 문서화
- [x] 에이전트 작업 규칙 문서화
- [ ] 시점과 카메라 결정
- [ ] 이동 및 공격 조작 결정
- [ ] 점수·질량·허기 관계의 첫 수치안 결정
- [ ] 변이 조건과 전투 규칙 결정
- [ ] 첫 프로토타입 성공 조건 정의

## Phase 1 — 로컬 핵심 수직 슬라이스

온라인 기능 없이 핵심 순환이 재미있는지 빠르게 확인합니다.

- 기본 생명체 이동
- 키보드·마우스 및 가상 조이스틱 입력
- 기본 먹이 생성과 섭취
- 허기 감소와 굶주림
- 점수·질량·외형 크기 증가
- 죽음과 생체 물질 생성
- 생체 물질 섭취와 변이
- 단순 포식자 공격
- 테스트용 AI 또는 로컬 다중 개체
- 기본 HUD

## Phase 2 — 생태계 밸런스 프로토타입

- 먹이 생성량과 수용 가능한 개체 수 측정
- 큰 개체의 유지 비용 검증
- 사체 환원율과 쟁탈전 검증
- 포식자 발생 빈도와 생존 시간 검증
- 반복 파밍과 스폰킬 대응
- 핵심 수치 데이터화

## Phase 3 — 온라인 기술 검증

Phase 1의 재미와 온라인 요구사항을 확인한 뒤 진행합니다.

- 네트워크 후보 비교와 결정 기록
- 서버 권위 범위 정의
- 이동 동기화와 보간 프로토타입
- 먹이·사체·변이 상태 동기화
- 접속·이탈·재접속
- 지연과 충돌 판정 검증
- 소규모 동시 접속 테스트

## Phase 4 — WebGL 플레이어블

- WebGL 빌드 자동화
- 브라우저 입력과 해상도 대응
- 로딩과 메모리 최적화
- 모바일 브라우저 지원 범위 검증
- 배포 환경 결정
- 외부 테스트 가능한 빌드 배포

## Phase 5 — 콘텐츠와 운영

- 최종 아트 콘셉트와 캐릭터 표현
- 사운드와 연출
- 스킨과 외형 성장
- 리더보드와 전적
- 계정 및 영구 데이터
- 운영·분석·크래시 수집
- 파티, 비공개 방, 시즌 등 확장 기능
