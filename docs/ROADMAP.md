## Phase 1 — 로컬 핵심 수직 슬라이스

온라인 기능 없이 핵심 순환이 재미있는지 빠르게 확인합니다.

### 진행 원칙 — 2026-10-17 사용자 승인

- 게임 규칙은 처음부터 `Shared/`의 순수 C# 시뮬레이션으로 작성하고, 로컬 슬라이스에서는 클라이언트가 이를 직접 실행합니다. Phase 3에서 서버가 같은 코드로 권위 판정을 합니다.
- 시뮬레이션은 `dt`를 받아 진행하며 고정 틱을 정하지 않습니다(서버 틱은 미결정).
- 수치는 모두 [밸런스 데이터 목록](BALANCE_PARAMETERS.md)의 항목 ID와 대응하는 설정 데이터의 **임시값**입니다.
- 단계마다 막히는 미결정 규칙은 아래 **임시안**으로 구현해 플레이로 확인합니다. 임시안은 확정 규칙이 아니며 [미결정 기획 항목](OPEN_DESIGN_QUESTIONS.md)에 그대로 남깁니다.

### 단계 순서

| 단계 | 내용 | 확인할 가설 | 임시안 |
| --- | --- | --- | --- |
| M1. 이동 코어 (`Shared/`) | 장치 독립 `PlayerCommand`(이동 벡터·대시), 약한 관성, 크기별 속도 감소, 대시·쿨타임, 마지막 유효 방향 | — | 첫 이동 전 대시 무시, 대시 비용 없음, 정지 판정 임계값 임시값 |
| M2. 입력 계층 (`Client/`) | WASD·방향키·좌하단 가상패드·마우스 추종 4모드 → 같은 `PlayerCommand`, UI·월드 입력 분리, 이동 테스트 씬 | 이동과 회피가 자연스러운가 | 마우스 중심 데드존 안 입력 0, 좌클릭 유지 시 누른 순간 1회만 대시, 모바일 터치는 기획서의 테스트 제안 |

| M6. 생태계 | 테스트 AI, 초식 사망 고기 드롭, 고기 섭취·몸집별 변이 요구량 증가·자연 감소·게이지·이상 피드백, 육식의 초식 먹이 밀기, 초식 밀침과 접촉 처치 | 자석이 원치 않는 변이를 강제하지 않는가, 접촉 즉사에 대응 여지가 있는가, 순환이 실제로 일어나는가 | 동률·작은 육식/큰 초식 생존은 확정, 점수 우위·섭취 우선은 확정, 동시 사망 반영·스폰 보호는 별도 결정 |

### 진행 상황

- [x] M1. 이동 코어 — `Shared/Runtime/Movement`, xUnit·EditMode 테스트
- [x] M2. 입력 계층 — `Prototype` 씬(구 `MovementTest`)에서 사용자 조작 확인 완료(Editor). 모바일·WebGL 미확인
- [x] M3. 먹이·성장 — `Prototype` 씬에서 사용자 확인 완료(Editor). M6 착수 전 확정 기획으로 재구현: 1000×1000 맵·5×5 타일 리젠·몸체 점유 차단·생성 타일 귀속·먼저 들어온 개체 선점(사망·이탈 시만 해제)·먹이 1개=1점·카메라 월드 경계 제한과 짧은 변 기준 시야. 재구현 후 사용자 플레이 확인 전
- [x] M4. 허기·플레이 흐름 — 공통 포만 감소·몸집별 먹이당 회복 감소·굶주림 사망, 결과 화면, 첫 화면 복귀. Editor Play Mode에서 흐름 확인, 사용자 플레이 확인 전
- [x] M5. 첫 화면 — 원형 몸체 + 귀·눈·표정 장식 placeholder 4종, 임시 팔레트 역할색·닉네임(임시 12자)·조작 4종 선택, 입장 시 PlayerPrefs 저장·첫 화면 진입 시 복원. EditMode 테스트와 Editor Play Mode에서 흐름 확인, 사용자 플레이 확인 전. 모바일·WebGL 미확인
- [x] M5.5 봇 플레이어 — `Shared/Runtime/Bots`, xUnit 테스트(인원 유지·지연 입장·도주·추격·먹이 탐색·수준별 생존). Editor Play Mode에서 나 + 봇 4명, 도주, 수준 0 굶주림과 재입장 확인. 사용자 플레이 확인 전. 육식 추격은 변이(M6) 전이라 개발용 역할 전환으로만 확인 가능
- [x] M6. 생태계 — 초식 사망 고기 드롭, 역할별 흡수·포만 회복, 고기 섭취 변이·몸집별 임계치·자연 감소·게이지·섭취 피드백, 육식의 초식 먹이 밀기, 초식 밀침, 접촉 처치(점수 엄격 비교·섭취 우선·임시 일괄 반영). xUnit 테스트와 Editor Play Mode에서 확인, 사용자 플레이 확인 전. 봇만 10분 진행 시 변이로 육식은 생기지만 처치 0건·육식 굶주림 → 사냥 가능성 밸런스 검토 필요
- [x] M7. HUD — 좌상단 랭킹(상위 10명·0.5초 갱신·내 순위), 모든 캐릭터 머리 위 닉네임·포만 게이지(화면 기준 일정 크기), 우상단 설정 버튼(개발용 패널·디버그 정보 토글), 우하단 대시 버튼(모바일·가상패드 모드, 쿨타임 표시). xUnit 랭킹 테스트와 Editor Play Mode 화면 확인, 사용자 플레이 확인 전. 모바일·WebGL 미확인
