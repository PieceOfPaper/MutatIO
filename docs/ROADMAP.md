# 개발 로드맵

- 문서 상태: 제안
- 마지막 갱신: 2026-10-17

이 로드맵은 기능 약속이 아니라 검증 순서입니다.

- [x] Unity 프로젝트와 저장소 생성
- [x] Unity CLI 및 Pipeline 패키지 포함
- [x] 핵심 생태계 규칙 문서화
- [x] 에이전트 작업 규칙 문서화
- [x] 몸집 증가에 따른 카메라 표시 영역 확대 방향 확정
- [ ] 정확한 시점·카메라 줌 곡선 결정
- [x] 방향 입력형·포인터 입력형 이동, 대시와 접촉 처치 방향 확정
- [x] 첫 화면의 네 조작 선택·좌하단 고정 가상패드·저장 방식 결정
- [x] 회전 제한 없음·약한 관성·큰 몸집 속도 감소와 대시 방향 정리
- [x] 수치·곡선 조정 항목을 밸런스 데이터 문서로 분리
- [x] PC 클릭 없는 마우스 추종·좌클릭 대시·UI 입력 분리 확정
- [ ] 모바일 터치 해제·마우스 중심·UI 위 이동·클릭 유지 대시 동작 결정
- [ ] 접촉 예외 규칙 결정
- [ ] 대시와 이동 수치 비교 테스트
- [ ] 점수·질량·허기 관계의 첫 수치안 결정
- [ ] 변이 임계치와 접촉 판정 세부 조건 결정
- [ ] 첫 프로토타입 성공 조건 정의

## Phase 1 — 로컬 핵심 수직 슬라이스

온라인 기능 없이 핵심 순환이 재미있는지 빠르게 확인합니다.

- 외형 선택·닉네임·조작 선택 입장 화면
- 기본 생명체 이동
- WASD·방향키·좌하단 고정 가상패드·터치/마우스 추종 네 선택지
- 캐릭터·닉네임·조작 선택 PlayerPrefs 저장·복원
- 회전속도 제한 없이 약한 관성·크기별 이동속도 감소
- 스페이스/PC 마우스 좌클릭/모바일 버튼 대시
- UI 버튼과 월드 이동·대시 입력 분리
- 초록색 초식 먹이의 공간 간격·주기 리젠과 자석형 자동 섭취
- 허기 감소와 굶주림
- 점수·질량·외형 크기 증가
- 초식 사망 시 누적 섭취량 비례 붉은 먹이 생성
- 생체 물질 섭취와 변이
- 크기 우위 육식의 접촉 처치
- 성장 연동 카메라 줌
- 테스트용 AI 또는 로컬 다중 개체
- 좌측 상단 랭킹·우측 상단 설정·머리 위 닉네임/포만 게이지
- 사망 결과와 확인 후 첫 화면 복귀

## Phase 2 — 생태계 밸런스 프로토타입

- 먹이 생성량과 수용 가능한 개체 수 측정
- 큰 개체의 유지 비용 검증
- 사체 환원율과 쟁탈전 검증
- 포식자 발생 빈도와 생존 시간 검증
- 반복 파밍과 스폰킬 대응
- 핵심 수치 데이터화

## Phase 3 — 온라인 기술 검증

Phase 1의 재미와 온라인 요구사항을 확인한 뒤 진행합니다.

- 네트워크 후보 비교와 결정 기록
- 서버 권위 범위 정의
- 이동 동기화와 보간 프로토타입
- 먹이·사체·변이 상태 동기화
- 접속·이탈·재접속
- 지연과 충돌 판정 검증
- 소규모 동시 접속 테스트

## Phase 4 — WebGL 플레이어블

- WebGL 빌드 자동화
- 브라우저 입력과 해상도 대응

- 모바일 브라우저 지원 범위 검증
- 배포 환경 결정
- 외부 테스트 가능한 빌드 배포

## Phase 5 — 콘텐츠와 운영

- 최종 아트 콘셉트와 캐릭터 표현

- 운영·분석·크래시 수집
